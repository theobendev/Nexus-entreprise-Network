# NEXUS Engineering — Enterprise Network Infrastructure Project

Architecture réseau hiérarchique (Core / Distribution / Access) pour une
entreprise fictive d'ingénierie sur site unique (~140 employés, 7 départements).

## Architecture

- **Core** : cœur de réseau, connecté à Internet
- **Distribution** : 2 switches regroupant les départements par zone (Administrative / Technique)
- **Access** : 7 switches d'accès (Direction, RH, Finance, R&D, Commercial, Support Technique, Invités)
